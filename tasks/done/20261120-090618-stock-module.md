Add a `stock` module to the inventory package (src/inventory/stock.py) with a `Stock` class that tracks item quantities:
- `add(sku: str, qty: int)` adds quantity; `remove(sku: str, qty: int)` removes it.
- Raise `ValueError` for non-positive qty, and a custom `InsufficientStockError` when removing more than available.
- `quantity(sku)` returns the current amount (0 for unknown SKUs).
The project's dev tools (ruff, mypy strict, pytest) must all pass. Use a local .venv for the dev dependencies.
