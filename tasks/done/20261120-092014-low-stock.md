## Goal
Let callers see which items are running low so they can reorder.

## Requirements
- Add `Stock.low_stock(threshold: int) -> list[tuple[str, int]]` returning (sku, quantity) pairs with quantity <= threshold, sorted by quantity ascending, then sku.
- `threshold` must be >= 0, otherwise raise `ValueError`.

## Acceptance criteria
- [ ] Returns an empty list for an empty stock.
- [ ] Items at exactly the threshold are included.
- [ ] Ties in quantity are ordered by sku.
- [ ] ruff, mypy (strict) and pytest all pass.

## Out of scope
- Persistence, CLI, or any change to add/remove behavior.
